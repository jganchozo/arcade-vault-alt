# Reference fonts

These local font files match the families and weights loaded by
`references/templates/Arcade Vault.html`:

- Press Start 2P: regular (400).
- JetBrains Mono: regular (400), medium (500), and bold (700).
- Courier Prime: regular (400) and bold (700), used as a fallback.

The files were obtained from the reference's Google Fonts stylesheet and are
served locally through `@font-face` in `app/globals.css`. Each family's SIL Open
Font License is included alongside the font files.
